Shuffling the labels — three candidates

Widget 5 asks could chance alone have produced what I saw? Under the null the grouping is meaningless, so any relabelling of the same numbers is equally likely. The animation has one job: make that undeniable — which is also the exact opposite of the bootstrap, where the values move and the labels are irrelevant.

Prior art. The Rossman/Chance Comparing Groups applet — the most-used tool in simulation-based inference teaching — does not swap or recolour. It pools every observation together and re-deals them into the groups. The pooling step is H₀ stated physically: there is only one group, and the split is a fiction. It also matches the card activity students often do by hand first, so it is an established convention rather than a private notation. That is candidate C.

All cells run the same seeded data and the same sequence of shuffles, in lockstep. Faint vertical guides mark each observation's value: if a dot ever leaves its guide, the data moved, and the whole claim is that it never does. Note the box labels — a permutation keeps the group sizes fixed, which is what separates it from randomly relabelling each observation independently.

  1. Does the pooling step in C earn its extra second? It is the only candidate that shows why relabelling is legitimate, but it is also the slowest and the busiest.
  2. In B, can you tell a swap from a re-deal? When dots cross directly between boxes, watch whether it reads as “these two traded places” — which is not what a permutation does.
  3. Do the boxes help? They make the group sizes fixed and visible. Or they add furniture to a figure that already has a lot.
  4. Does any dot appear to leave its value guide? If so the candidate is lying about the mechanism and is out, however nice it looks.

Token gap this mockup exposes. There is no semantic role for “one arm of a comparison”. The five roles are empirical, theory, smoothed, highlight, reference, and none of them means “group B” — so this page borrows --series-1 and --series-2 directly, which the house rules forbid in a real widget. Widgets 4, 5 and 6 all show two groups, so this wants deciding once: probably --c-group-a / --c-group-b in tokens.css. Note --series-2 is also --c-theory; that collides if a figure ever shows two groups and a theoretical curve.
