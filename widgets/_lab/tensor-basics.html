tensors · a Basics topic, and how the topics are organised

Two asks from the first test of the draft. A Basics topic: students set the dimensions themselves — add one, remove one — and see the same tensor in the stack view, the frames view and as PyTorch prints it, then index into it, which is the step that confuses. The organisation: the draft's four topics are the lesson's two halves run together — Tensors for Data (shape, index, reshape, join) and Linear Algebra (elementwise and broadcasting, three kinds of multiplication, reductions) — and the question is whether those halves are two rows of one rail, or two widgets. §1 mocks the rails; §2 the Basics stage.

§1 · Where the topics live — three rails

A one widget, one row of five. B one widget, the rail in two captioned rows, the lesson's own halves, using the grouped segmented the Operation control already uses. C two widgets on the gallery, tensors and linear-algebra, each with its own three topics; the Multiply topic then has room for the lesson's three multiplications as a control of its own — matrix product, dot product, Hadamard product — which the draft leaves to slot 50's dropout mask. Every rail is drawn at the rail's real width, 300px, so the truncation is real.

§2 · The Basics stage — set the dimensions, then index

The rail would carry Dimensions as a control — add one in front, remove the first — from rank 1 to rank 4, each rank the lesson's own example: [5] a feature vector, [2, 5] two samples, [2, 2, 5] two samples of two sequence points, [2, 2, 2, 5] a batch of two of those. The stage draws the tensor in the chosen view with the dimension arrows named, and prints it, exactly as the Shape topic does. Then Index: one control per dimension, each an index or :, so the reader builds T[1, 0, 2] or T[:, 0, :] and sees the cells it selects lit in the drawing and in the print, with the selection's own shape and print beneath. Step is not needed: the controls are the interaction, as on the Partial derivatives tab of gradients.

What Basics settles that Shape cannot. On Shape the tensor is fixed and the operation moves; on Basics the tensor's rank moves and nothing else does, so a reader can watch one more bracket appear in the print and one more frame appear round the drawing, and can read T[1, 0, 2] off the edges before the reshape topic asks where 13 went. The index control is the lesson's cells 19–23 (one element; a sample; a sequence point across samples; a feature across everything).
