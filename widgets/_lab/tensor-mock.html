Slot 53 · tensors — the tensor, where a value goes, when shapes combine

Every number on this page is the lesson's own (05-2 cells 3–69): the [2, 2, 5] tensor holding 1–20 with the dimensions named sample, sequence, feature; X [2, 5] + b [5] for broadcasting; X [3, 4] @ Wᵀ [4, 2] for the layer as a matrix product; X [3, 4] reduced over dim 0 and normalized. The device is that every cell carries its value, so the reader can see where 11 went after a reshape and after a permute, which cells the second row of the product read, and which cells a mean over dim 0 collapsed. Nothing here is measured; what the mock has to prove is legibility — twenty numbered cells and their result at the 550px fingerprint width — and which drawing of a three-dimensional tensor reads.

Colour roles are provisional. The tensor being operated on is washed --c-group-a, the second operand --c-group-b, the result --c-empirical (what the operation built), the cell moving or being computed --c-highlight, the cells it reads outlined in the same. A failing case prints in --c-extreme. §1 C tries one colour per dimension, carried into the shape.

§1 · How a three-dimensional tensor is drawn — the same [2, 2, 5]

A the lesson's own picture: one 2 × 5 grid per sample, stacked with an offset, the three dimensions as arrows labelled by index and role; B flat: the two samples side by side, the shape written once, no perspective — cheaper, and every cell is fully visible; C A with each dimension in its own colour, the colour repeated on its entry in the shape, the lesson's reshape figure. Hover (not drawn) would print a cell's index T[i, j, k] and its value in the readout on every tab.

§2 · Where a value goes — reshape against permute to the same shape

The stage that loses. reshape(2, 5, 2) and permute(0, 2, 1) both produce a [2, 5, 2] tensor and the contents differ: reshape reads the values in order and cuts the sequence anew, permute moves each value to the index with its last two positions swapped. Both panels are seven moves in; the moving value is highlighted on both sides. Then the lesson's other shape operations on the same tensor, each finished: reshape(2, −1), flatten(), unsqueeze(0). The pick is whether cat and stack (cells 41–44, a second tensor of 21–30) are two more options of the same control or cut.

§3 · Broadcasting — X [2, 5] + b, five shapes of b

The lesson's rule, drawn: line the shapes up from the right, a missing dimension counts as 1, equal or 1 passes, anything else is an error. The stretched copies are drawn faint where the lesson's figure draws a dotted arrow. b of shape [5], [1, 5], [2, 1], a scalar, and [2] — which fails (2.6): the case a reader who lines shapes up from the left expects to work.

§4 · Matrix multiplication — X [3, 4] @ Wᵀ, one output cell at a time

The lesson's neuron example: three data points with four inputs, two neurons with four weights each. Step computes one cell of the product — the row of X and the column of Wᵀ it reads are lit and the four products are written and summed, which is a dot product. Left, three cells done and the fourth in progress; right, X @ W without the transpose, where the inner dimensions are 4 and 2 and there is no product to draw. Widget 37 draws this same layer as edges; here it is a grid.

§5 · Reduction — X [3, 4], which dimension disappears

mean(dim=0) collapses the three rows into one row of four: the dimension named is the one that goes. mean(dim=1) collapses the four columns into one column of three; no dim collapses everything to one number. Then the lesson's payoff: (X − μ) / σ with μ and σ both [4], which is a reduction followed by a broadcast — the two previous tabs composed, and the normalization widget 48 standardizes x with.
