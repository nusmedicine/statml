6 · Found in the lessons

08-1 cell 14 freezes with model.backbone.parameters(). A BertForSequenceClassification has no backbone; it is model.bert, as 08-2 cell 20's table says. The snippet raises AttributeError.

08-1 cell 15 describes LoRA as small adapter layers inserted between transformer blocks. That is adapter tuning. LoRA adds a low-rank bypass beside existing weight matrices (for BERT, peft's default is query and value), scaled by α/r, which the formula W' = W + ABᵀ leaves out.

08-3 cell 85 occludes ESM-2 with PAD_IDX = aa_vocab["*"] = 0, the scratch model's vocabulary. In ESM-2's tokenizer id 0 is <cls> and <pad> is 1 (read from its tokenizer, 2026-09-25), so the window is filled with copies of the start token. The window also slides over <cls> and <eos>.

08-3 cell 4, Handling Padding: src_key_padding_mask=src_key_padding_mask uses a name the line above never defines (it defines padding_mask). Cell 28 has it right.

08-3 cell 1's table (long-distance relations: CNN No, transformer Yes): on the stage in § 4 a CNN with a global max carried two sites 64 apart into a linear head at 100%, and the lesson's transformer trained from scratch reached 65%. A window cannot see a distant PAIR's arrangement; a global max still carries both motifs' presence. And from scratch on a lesson-sized set the transformer is the harder model to train, which is the notebook's own case for its pretrained half.

08-2 cells 67 and 72 keep only positive attributions. In 52 of 120 toy notes a no pushed against the predicted class and would print as zero.

08-3's transfer run: EsmForSequenceClassification's head reads position 0, <cls>. ESM-2 was pretrained by masked tokens alone, so with the backbone frozen that position was never trained as a summary (cell 4's own caveat). The toy: [CLS] 91–97% against the mean's 99–100%.

dl-language-pretrain-lora.png writes W′ = ABᵀ, without the frozen W the text keeps; and dl-language-pretrain-adapt.png draws PEFT as an Adapter box between backbone and head, adapter tuning's picture rather than LoRA's. 85's LoRA page would be drawn on these.

peft has no default LoRA targets for ESM-2: LoraConfig without target_modules raises on esm2_t6_8M_UR50D; with query and value it trains 164,802 of 7,677,245 (2.15%). Worth knowing if 08-3 gains a PEFT run; today it runs transfer only.

08-1 cell 4 (minor): BERT's masking is 80% [MASK], 10% a random token, 10% unchanged, not always [MASK].
