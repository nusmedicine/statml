What the two questions are

The tween (A–E). Each subject currently travels a straight line from its grid cell to its landing spot, and the vertical half of that line carries nothing: a subject's grid ROW is unrelated to its stack ROW, which is assigned by collision on the value axis. Release order is grid order and landing order is value order, so about half the flights swap places in mid-air, and the per-subject offset only delays the start — everything still lands on the same frame, so the crossing is worst exactly at the end.

The blocking (F, G). Blocking IS a partition: you split the population by the confounder and then sample within each part. F never shows that act — the boxes simply land in the right proportions. G sorts the population into its two blocks first, and the same beat then explains all three schemes: Convenience takes everything from one block, Block takes equally from both, and Randomize skips the sort entirely, which is itself the difference between them.
