0 · What the lesson does, and what came out

Cell 84 defines two masks, a node feature mask Mx ∈ RN×F and an edge mask Me ∈ RE, learned so that the masked graph's prediction "stays close to the original prediction": "the smallest set of atoms/bonds and features that preserve the model's output." Cell 86 runs PyG's GNNExplainer(epochs=300, lr=0.01) on the model's own prediction. Cell 90 scores an atom as the mean |mask| over its features and a bond as the larger of its two directions, each scaled 0–1 within the molecule; cell 92 draws them as a heat overlay. test_set[3] is row 76, ceftriaxone disodium (active), whose SMILES carries three waters and two Na+ as five separate one-atom pieces of the graph.

2 · Mask page — the mask is learned (300 epochs, from a random start)

The edge mask itself, before cell 90's scaling: each bond's sigmoid value (0 removes the bond's message in both layers, 1 keeps it). The start is random (PyG: normal noise, sd ≈ 0.22 for 41 atoms), so every bond begins near 0.5 — and with every feature also near half, the first prediction is p(active) = , not . The optimiser then raises p back and pushes each mask value toward 0 or 1 (the size and entropy terms). Four frames of one run, then the run's curve. The bonds move late and not far: at the lesson's 300 epochs about half of them ( over 20 runs) still sit between 0.1 and 0.9 — a heat map of an unfinished optimisation, which cell 90's 0–1 scaling does not show.

3 · Runs page — each run keeps a different set of bonds, and each set works

A bond counts as kept when its mask ends above 0.5. Each run's kept bonds alone hold the prediction (every other bond's message removed, every atom's features intact) — well above random sets of the same size. But two runs keep different sets: median Jaccard across the 20 runs' 190 pairs; every one of the 39 bonds is kept by some run, and only by every run — the three bonds of N10, the β-lactam ring's nitrogen. Running 3,000 epochs instead of 300 makes every mask exactly 0 or 1 and leaves the runs as far apart (top-5 bonds shared: median 1 of 5 at 100, 300, 1,000 and 3,000 epochs). Four runs, then all twenty.

4 · The waters and the sodium are scored — and the model does read them

No bond joins them to the drug, so no message reaches them and none leaves. But the lesson's GAT pools with max over every atom (cell 64), so a water's vector can supply a channel's maximum. Setting one water's features to 0 moves p(active) by — more than deleting any one bond except one (largest single bond: ). 6 · The calls

What 98 adds to 87. 87's attributions are formulas: integrated gradients and occlusion give the same answer every time. GNNExplainer learns its answer by optimisation, from a random start, as a set of bonds — and the measurement says that set is one of many. The picked claim: a highlighted bond is part of one set that keeps the model's prediction, not the reason the molecule stops E. coli growing, and another run picks another set.

7 · Notebook findings, to tell you

1. Cell 86 sets no seed for GNNExplainer, and its masks start random: re-running cell 90 gives another picture. On this molecule two runs share a median of 1 of their top 5 bonds.
2. Cell 90's atom score is the mean |mask| over all 39 features, and PyG sets the mask to 0 on every feature that is 0 for that atom (no gradient), so the score partly counts how many features an atom has switched on (Spearman with that count on this molecule; when the mean runs over the atom's own features only).
3. The salt's waters and Na+ are scored and, through max pooling, the model reads them (§ 4); the drawing in cell 92 places them among the drug's atoms.
4. The masked starting point flips the prediction (p(active) at epoch 1), because each feature, atomic number included, is multiplied by about 0.5; the optimiser recovers it within ~50 epochs.
