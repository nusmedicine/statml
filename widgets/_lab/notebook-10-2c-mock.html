Typical Usage

  • When one modality provides context for interpreting another (e.g., text attending to image features).
  • When one modality is best kept as separate features (e.g., each mutation, each image patch, each word of a text), and the relevance of each feature depends on the other modality.

Considerations

  • In cross-attention, A attends to B: the query comes from A, and the keys and values come from B.
    • A's features are combined into one embedding per sample, used as the query.
    • B is encoded as a sequence of tokens, one embedding per feature, used as the keys and values.
# Shapes only, not runnable code
# B: batch size   D: embedding size   F_A, F_B: features of A and B   L_B: tokens from B
xA                                          # (B, F_A)      modality A, e.g., expression of F_A = 100 genes
xB                                          # (B, F_B)      modality B, e.g., status of F_B = 50 mutations

zA = encoderA(xA)                           # (B, D)        A's features combined into one embedding per sample
Q  = zA.unsqueeze(1)                        # (B, 1, D)     a sequence of length 1: one query per sample
K = V = encoderB(xB)                        # (B, L_B, D)   one token per feature of B (here L_B = F_B = 50)

attn_output, attn_weights = cross_attn(Q, K, V)
# attn_weights                              # (B, 1, L_B)   one weight per token of B
# attn_output                               # (B, 1, D)
h = attn_output.squeeze(1) + Q.squeeze(1)   # (B, D)        plus the query (residual connection)

Cell 6 · ### Co-Attention · the whole cell up to the template

Co-Attention

This is the symmetric form of cross-attention.

  • Each modality attends to the other: A's tokens are queries over B's tokens, and B's tokens are queries over A's tokens.

Mathematically,

HA = softmax(QAKB⊤/√d) VB + ZA,   HB = softmax(QBKA⊤/√d) VA + ZB,   h = [mean(HA) ‖ mean(HB)],   ŷ = g(h)

where:

  • ZA, ZB are the two token sequences, and adding them back is the residual connection,
  • each side's attended tokens are averaged into one vector, and the two vectors are concatenated.

Typical Usage

  • When both modalities are best kept as separate features and each provides context for the other (e.g., the image patches and the words of a radiology report, or genes and mutations).

Considerations

  • In co-attention, A attends to B and B attends to A, so both modalities are encoded as sequences of tokens, one embedding per feature.
# Shapes only, not runnable code
# B: batch size   D: embedding size   F_A, F_B: features of A and B   L_A, L_B: tokens from A and B
xA                                          # (B, F_A)        modality A, e.g., expression of F_A = 100 genes
xB                                          # (B, F_B)        modality B, e.g., status of F_B = 50 mutations

zA = encoderA(xA)                           # (B, L_A, D)     one token per feature of A (here L_A = F_A = 100)
zB = encoderB(xB)                           # (B, L_B, D)     one token per feature of B (here L_B = F_B = 50)

hA, attn_AB = attn_AB(zA, zB, zB)           # attn_AB (B, L_A, L_B): for each token of A, one weight per token of B
hB, attn_BA = attn_BA(zB, zA, zA)           # attn_BA (B, L_B, L_A): for each token of B, one weight per token of A
hA, hB = hA + zA, hB + zB                   # (B, L_A, D), (B, L_B, D)   residual connections
h = torch.cat([hA.mean(1), hB.mean(1)], 1)  # (B, 2D)         each side averaged over its tokens, then concatenated
