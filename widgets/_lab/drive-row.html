Every block below is at a real width — 262 px is the control rail under layout:"side", 694 px is the stacked shell the other six widgets use — and each one prints its own measured line count, so a verdict here cannot disagree with the picture above it.

That self-measurement earned itself twice over. The first harness got this page's own answers wrong in both directions: variant A looked fine because the private row class had silently dropped the shipped margin-left on Reset, and every clustered variant looked like it wrapped because a button inside a group sits ~1 px off one standing bare beside it, which counting distinct rounded tops read as a second row. Both are fixed; the numbers below are measured against the real .w-drive.

Principle 3.4 is what to check against. Every drive button is the same size; emphasis comes from weight and ink, separation from a gap — “never from geometry”. That clause was written about making Reset smaller. A cluster keeps every button the same size, so it is consistent with 3.4 — but close enough to the line to say out loud.
