10-2c · Cross-Attention: wording for "which modality attends to which"

The confusion is real: expression is 100 genes, so it is "many parts" too. What differs is not the data but how the model uses each modality: the query side is summarized into one vector per sample (one question), and the key/value side is kept as a list of items, one embedding each, so each item can get its own weight. Any modality can play either role. Four ways to say it, each a drop-in for your Typical Usage + Considerations block.

A · Summarized versus kept as a list

States the mechanism plainly; no analogy.

Typical Usage

  • When one modality provides context for interpreting another (e.g., text attending to image features).
  • When you want to weigh the individual items of one modality (each mutation, pathway, image patch or word), and which items matter differs from sample to sample.

Considerations

  • Both modalities may have many features. What differs is how the model uses them. When A attends to B:
    • A is summarized into one vector per sample, the query. It decides the weights.
    • B is kept as a list of items, one embedding per item: the keys and values. Each item gets a weight.
  • So put on the B side the modality whose items you want to weigh one by one, and on the A side the modality that should decide those weights.

B · Fill in the blank

Turns the choice into the biological question; the direction falls out of the sentence.

Typical Usage

  • When one modality provides context for interpreting another (e.g., text attending to image features).
  • When the question has the form "Given this sample's ___, which ___ matter?"

Considerations

  • Fill in the question to choose the direction:
    • the first blank is the query: summarized into one vector per sample;
    • the second blank is the keys and values: kept as a list of items, one embedding each, and each item gets a weight.
  • "Given this tumour's expression, which mutations matter?" → expression attends to mutations.
    "Given what is mutated, which pathways matter?" → mutations attend to pathways.

C · A search, as an analogy

Matches the names query / key / value; some students know it from search engines or databases.

Typical Usage

  • When one modality provides context for interpreting another (e.g., text attending to image features).
  • When one modality is used to search the items of the other, and the relevant items differ from sample to sample.

Considerations

  • Attention works like a search. When A attends to B:
    • A is the query: what is being searched for, one vector per sample;
    • B's items are what is searched: each has a key (compared with the query) and a value (what is returned);
    • the result is the values, weighted by how well each key matches the query.
  • So B should be the modality whose individual items (mutations, pathways, image patches) are worth searching.

D · A and B side by side, as a table

One glance; the "many features" confusion is answered in its first row.

Typical Usage

  • When one modality provides context for interpreting another (e.g., text attending to image features).
  • When the items of one modality should be weighed one by one, differently for each sample.
