2 · Encoder against decoder: change a later token, which rows move?

Your first point, as one comparison on one sentence. Left the encoder, right the decoder; each draws its block-1 weights (the decoder's triangle is the causal mask) and, beneath, how far each token's final vector moves when the token chosen below is replaced. In the encoder every row moves, because every row attends to the change; in the decoder the rows before it move by exactly 0, which is what lets it generate one token at a time and train on every position at once. Measured on three pairs: encoder rows before the change move 4.0–11.2, decoder rows 0.00.

3 · Cross-attention: queries from one sequence, keys and values from another

Your second point. A, the draft's DNA → protein staircase (0.95 of each amino acid's weight on its own codon). B, what 10-2's template does: it unsqueezes each modality's embedding to one token, (B, 1, D), so the softmax runs over one key and every weight is exactly 1.0. Measured with nn.MultiheadAttention: three very different queries give outputs 0.0 apart, so modality A never reaches the prediction; with six key tokens the weights spread (0.14–0.19) and the output moves with the query (0.41).

B · the same query row over six keys, and over one

A page of 84 with a Keys control (the gene's 18 nucleotides · one pooled vector): the staircase, then the one-key case, whose row is 1.00 whatever the query. 10-2 can link the same page.

For 10-2 cell 5. With Q and K each (B, 1, D) the attention weight is always 1, so h = W_O(W_V z_B + b): modality A is ignored. Cross-attention needs several key tokens (the mutations, or image patches, as tokens), or it is a linear map of B.
