The equation, the link figure, and what the strip's height means

Three questions from review, drawn at the real 550px stage.
— the equation should be MathML and should name its covariates;
— the little link figure has p on x while the panel below it has p on y, which is a 90° disagreement inside one figure;
— and the strip has no axis, so what its bars measure is a guess.

Round 1 — the equation

All four are MathML. One <math> per term, because a single one does not line-break — MathML Core treats white-space as nowrap on every element and no engine implements automatic linebreaking, so a long equation in one <math> simply overflows. Separate inline elements with real whitespace between them break at the seams, and the seams are authored.

Round 2 — the link figure, and which way p runs

The panels below the card put p on the vertical axis. L1 is what is built and puts it on the horizontal one, which is the disagreement. The literature's conventional plot is L1, so this is a choice between matching convention and matching the figure it sits above — and the figure it sits above is the one the reader is looking at.

Round 3 — what the strip's height is

The bars are the change in that panel's own quantity for one step, each strip scaled to its own largest. The row label says step, which names what CAUSED the change rather than what is being measured — so the honest fix is a label that names the quantity, and then the question is whether a number is needed too.
