0 · What the measurement found

1 · The stage: a 200-mer padded to 250, two tasks

The lesson's data is coding against intergenic 200-mers (every one exactly 200 bp, padded to MAX_LEN = 250) and, later, influenza HA proteins. A page that reads a kernel as a motif needs a motif that IS the evidence, so the motif task plants TGACTCA (the AP-1 site) in a random 200-mer. A recurrence at H = 8 never finds a 7-mer in 200 random bases in any budget measured, but it reads composition (GC-rich against GC-poor, the lesson's task in proxy) — so the stage offers both, and each model has a task it can win.
