Slot 89 · showing what imputation does to the conclusion

Today the conclusion is one readout tile, “Proteins called, adjusted p < 0.05: 91 of 465”, and the false calls appear only in its note under True values On — for one method at a time. The conclusion students should see is that the list of significant proteins changes with the method. Two ways to draw it, as a panel at the foot of the Imputing page (550 px). Numbers from the widget's engine, seed 2; the test is the widget's (Welch t on log2, Benjamini–Hochberg, adjusted p < 0.05).

A · every method side by side — the current one highlighted

One bar per method: the proteins it calls. True values Off: just the count, as a real analysis sees it. True values On: the bar splits into real differences found and false calls, and an outline shows the real differences the test missed. The FDR is printed at the bar's end. Method = Mixed highlighted.

B · a volcano plot for the method on screen

01-4's own figure: log2 fold change across, −log10 adjusted p up, the 0.05 line. True values On colours the false calls. The marked protein is ringed. Comparing methods means switching Method and watching the cloud move.
