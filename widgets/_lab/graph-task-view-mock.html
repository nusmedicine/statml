1 · Node features for the proteins

A link-prediction model reads x too: it scores a pair from the two proteins' vectors after message passing, so without features it has only the wiring. Two readable features, from UniProt, beside the network as on Patients: length (amino acids, in thousands) and kinase (1 for ATM and CHEK2, the two kinases here). Real models use a learned vector per protein (a sequence embedding), which a detail can say. Lengths: TP53 393, MDM2 491, CDKN1A 164, ATM 3,056, CHEK2 543, BRCA1 1,863, BARD1 777, RAD51 339, BRCA2 3,418, PALB2 1,186.

2 · The task, marked on each example

Same tables, different question, drawn with the unknown colour and a "?": on Patients one patient whose subtype is unknown (patient 1, which sits between the two groups), open, "?" in the node and in y — the node-level task; on Interactions one pair with no edge on record, dashed with a "?" (TP53–BRCA1) — the edge-level task; on Molecule the task is already the y · [1] tile, so the table gains nothing (a "?" there would mean a molecule with no label, which the table has none of). Not the split: one query each, in the unknown colour, where the split's held-out marks are red and on the split view only. The tile that names the task says it in words: "Task: node-level · predict a patient's subtype", "Task: edge-level · predict whether two proteins interact".

3 · The split as a view of the example on screen

The split stops being a page with an Example control of its own. It becomes a second view of whichever example is selected, so it always belongs to the example above it: pick Interactions, then Split, and the Interactions split appears; pick Patients while Split is on and it changes to the Patients split. The diagram heads the split view with that example's panel framed, and a click on another panel switches the example, staying on Split. Representation is the default, so an example opens as data. On Graph the control is hidden: Graph has no task. A press on Molecule survives a visit to its split view and back.

Recommended: 1A, 2 as drawn, 3A. Real features a student can read; one "?" per example in the unknown colour, named by a Task tile; and the split as a view that inherits the example, which removes the second Example control and the mismatch it caused.
