2 · Can it all be one function? Yes — it takes the tidyproteomics object, not the table

The function impute() calls must hand back a table of the same size, so it cannot remove proteins. The filter therefore sits in an outer function that takes the whole object: it filters, then calls impute() with the mixed rule. For students it is one call: rdata_mixed <- impute_mixed(rdata_unimputed).

impute_mixed <- function(data, keep_prop = 0.5, mnar_prop = 0.2) {
  # Step 1, filter: keep proteins measured in at least keep_prop of the samples of one group
  measured <- data %>%
    extract() %>%
    complete(identifier, nesting(sample, replicate)) %>%      # a missing value becomes NA
    group_by(identifier, sample) %>%
    summarise(prop = mean(!is.na(abundance)), .groups = "drop") %>%
    group_by(identifier) %>%
    summarise(annotation = if_else(max(prop) >= keep_prop, "yes", "no"))
  # subset() compares a column with a value, so add the result as an annotation first
  data$annotations <- data$annotations %>%
    bind_rows(measured %>% transmute(protein = identifier, term = "keep", annotation))
  data <- data %>% subset(keep == "yes")

  # Step 2, impute: the minimum for proteins measured in at most mnar_prop of the
  # samples of some group (MNAR), random forest for the rest (MAR)
  mixed <- function(m, ...) {
    group <- sub("-sep-.*", "", colnames(m))           # "cancer-sep-1" -> "cancer"
    prop <- sapply(unique(group), function(g) rowMeans(!is.na(m[, group == g, drop = FALSE])))
    mnar <- apply(prop, 1, min) <= mnar_prop
    filled <- missForest::missForest(m)$ximp           # random forest fills every missing value
    use_min <- is.na(m) & mnar                         # then MNAR proteins get the minimum instead
    filled[use_min] <- min(m, na.rm = TRUE)
    filled
  }
  data %>% impute(.function = mixed, method = "matrix")
}

### In practice

Random forest assumes a missing value is like the measured ones (MAR). In mass spectrometry, many values are
missing because the protein is below the detection limit (MNAR), so the true value is lower than anything
measured. Random forest fills these too high, which can hide a protein that is present in healthy samples but
below the limit in cancer.

A single missing value cannot tell us why it is missing, so each protein is judged by how many samples it was
measured in, in two steps:

1. **Filter.** Remove proteins measured in too few samples to impute from: keep a protein if it was measured in
   at least half of the samples of one group. Stricter thresholds (70%, or every sample) are also used; they
   remove more proteins.
2. **Impute by protein (mixed imputation).** A protein measured in at most 20% of the samples of a group (2 of 11
   here) is treated as below the detection limit in that group (MNAR), and its missing values get the lowest
   value measured in the data. All other missing values are imputed with random forest (MAR).

`tidyproteomics` does not have mixed imputation built in, so the function below does both steps:

- `keep_prop`: keep proteins measured in at least this proportion of the samples of one group (0.5, 0.7 or 1)
- `mnar_prop`: give the minimum to proteins measured in at most this proportion of the samples of a group (0.2)
