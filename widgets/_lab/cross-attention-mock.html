**Example: cross-attention**

The expression embedding asks one question per patient (the query); each of the 50 mutations becomes one token (a key and a value).
- Each mutation has a learned vector. A patient's token for that mutation is the vector if they carry it, and zeros if they do not.
- The attention weights over the 50 tokens sum to 1. The attended vector is the weighted average of the tokens, and the head predicts from it.
code · the mutation tokens
class MutTokenEncoder(nn.Module):
    def __init__(self, num_muts, embed_dim=64):
        super().__init__()
        self.mut_embed = nn.Embedding(num_muts, embed_dim)   # one learned vector per mutation

    def forward(self, x):                                     # x: (B, num_muts), 0 or 1
        vectors = self.mut_embed.weight                       # (num_muts, D)
        return x.unsqueeze(-1) * vectors                      # (B, num_muts, D); not carried = zeros
code · cell 5's template, with the weights kept
class CrossAttentionFusion(nn.Module):
    def __init__(self, encoderA, encoderB, embed_dim, head_hidden=128, num_heads=1, num_classes=2):
        super().__init__()
        self.encoderA = encoderA   # query: expression
        self.encoderB = encoderB   # keys and values: mutation tokens
        self.cross_attn = nn.MultiheadAttention(embed_dim=embed_dim, num_heads=num_heads, batch_first=True)
        self.fusion_head = nn.Sequential(
            nn.Linear(embed_dim, head_hidden),
            nn.ReLU(),
            nn.Linear(head_hidden, num_classes)
        )

    def forward(self, xA, xB):
        Q = self.encoderA(xA).unsqueeze(1)    # (B, 1, D)
        K = self.encoderB(xB)                 # (B, 50, D)
        V = K
        attn_output, attn_weights = self.cross_attn(Q, K, V)   # (B, 1, D), (B, 1, 50)
        self.attn_weights = attn_weights.squeeze(1)            # (B, 50), kept for the plot
        h = attn_output.squeeze(1)
        return self.fusion_head(h)            # (B, 2)

(d) Comparisons that hold on all five seeds, and those that do not

Why not id + status tokens

Share of each test patient's attention on the mutations they carry (they carry 12.8% of the 50 on average), per seed. With id + status embeddings the model attends to carried tokens on two seeds, to absent ones on another, and in between on two; with the multiplied tokens the share is the same on every seed. Its carrier-conditional driver ranks move just as much (on seed 3 mutation 39 ranks 21st).

(e) Calls

What a student would conclude, and whether it is true “Cross-attention found the driver mutations.” Mostly true when read among carriers: mutation 39 ranks 1st to 4th and 14 ranks 1st to 8th on every seed, and at least four of the five drivers are in the top ten on every seed; the fifth driver drops out on two seeds (31 on seed 42, 8 on seed 4). Carried non-drivers get about the same weight as an absent mutation. “Mutation 27 does not matter.” False. It is half of the gene-8 interaction and is never among the attended mutations (rank 12 to 49). A low weight is not a low importance; that is the lesson the plot can teach. “Cross-attention is the better fusion.” False here: 0.71 against concatenation's 0.77. In the template the expression reaches the head only through the weights (the attended vector is built from mutation tokens alone). No leak: the tokens carry nothing but the 0/1 status, and the weights are not just the status (carried non-drivers sit on the floor).
