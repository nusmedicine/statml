tensors · squeeze and unsqueeze — what the figure can show

Your questions 3 and 4, on round 21. The figure draws four dimensions, and since round 21 a fifth when it is a size-1 dimension in front. That one rule decides everything below. Nothing has been changed in the widget for this page; the crops in §1 are the widget itself, live, cropped to its stage.

§1 · What is built now

unsqueeze draws at every position at ranks 1–3, because the result has at most four dimensions. It is only at rank 4 that the result has five, and there only position 0 (or −5) is drawn. squeeze's source is the tensor unsqueeze(0) made — cell 34's own example, "we previously added the batch dimension 0 so our tensor is [1, 2, 2, 5]" — so dim 0 is the only size-1 dimension there is, and any other position leaves the shape as it is, which is what cell 34 says torch does. So yes: today, squeeze can only remove dim 0 because only dim 0 has one entry. That is the source, not the figure.

§2 · The options

A · as built, with the hint on the declined positions saying what does draw ("a fifth dimension, drawn only in front (0); every position draws at ranks 1–3") and squeeze's detail saying why other positions leave the shape ("the source has one entry only in dim 0"). No code beyond two strings.

B · squeeze's source carries its size-1 dimension where you put it (recommended). squeeze gains a second dropdown, Size-1 dimension at, and its source is T.unsqueeze(k) for that k — the same tensor the unsqueeze row above it just drew. Then Dimension to remove has something to remove at every position: squeeze(1) on [2, 1, 2, 5] gives [2, 2, 5]; squeeze(0) on the same tensor leaves it unchanged, which is cell 34's rule seen rather than read; – removes it wherever it is. At rank 4 the only k the figure draws is 0, so the second dropdown offers 0 there and the tab reads as it does today. Cost: a second dropdown, one model change, a round.
