§1 · He is right, and the reason is what the gradient is FOR

Backpropagation computes a gradient for every parameter — the two layers of weights and the biases. The inputs are data: they have no parameter and receive no update, so an arrow landing on them promises something that never happens. What the backward pass actually reaches, in a network with one hidden layer, is the hidden units: the error at the output gives the gradient for the hidden→output weights directly, then it is carried to each hidden unit, and each unit's share gives the gradient for its own input→hidden weights. The signal stops there because there is nothing beyond it to change.

A is what ships now, and its arrow reaches the input nodes — the thing to fix. B stops the arc at the hidden column. C routes the same path as a right-angled elbow over the top, which reads as a return path rather than a second forward sweep — the curve in A and B can be misread as another arc from left to right. D drops the overhead route entirely and sends the error back along the edges themselves, which is literally where the gradient flows, with each hidden unit ringed as it receives its share.
