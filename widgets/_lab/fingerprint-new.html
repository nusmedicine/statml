Hash new fingerprint states

Computes px and tx for a handful of NEW states directly, so they can be pasted into fingerprint-baseline.json ready-made. This is not a second copy of the suite. The suite’s job is to prove the widgets you are not looking at still render identically; this one’s job is to learn a few numbers. Welding them together means re-verifying every known-good state twice over to record four — which is the loop NEVER BASELINE BY PLACEHOLDER-AND-DIFF exists to forbid.

Each state is hashed three times. A driven state that is not identical across three runs is flaky, and a flaky check is worse than none. Run the full suite once afterwards; that run is the confirmation and the only one needed.
