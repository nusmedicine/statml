Hover mode

Recommended: P1 for the padding, and H1 + H2 for hover. P1 marks the [PAD] block as a block, which is what padding is, and leaves every cell's own colour alone, so an unmasked [PAD] weight reads as clearly as any other. H1 answers "where does this weight come from?" by walking one number back through its strips; H2 is its reverse, one key's column down the matrix. H3 is H1 with the key left out.
