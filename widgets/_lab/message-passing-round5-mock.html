0 · What others do (research, 2026-10-09)

  • GNN101 (Lu et al. 2024, a browser tool for teaching GNNs): each layer's input and output are drawn as separate copies of the graph; hovering a node in the output lights it and the nodes it read in the input. One node is the focus, and the copies make plain that every output node is computed from the same, unchanged input.
  • Synchronous message passing is the standard assumption (Dudzik et al. 2024): every message in a layer is made from the previous layer's values, sent and received at once; no node reads a neighbour already updated in the same layer. A single copy that changes node by node shows exactly the wrong thing.
  • Your own figure (dl-layer-gnn.png) is already drawn this way: Input on top, Output below, the graph copied.

1 · Basics — one node in focus, every node updated

Arm C, two copies. The top copy is the layer's input h and never changes during the press; the bottom copy is h′. Aggregate draws every node's incoming lines (grey, thin: every node reads at the same time), moves only node 1's three rows down its own lines (violet, the focus), and fills the whole bottom row at once. Because every new value is read from the unchanged top copy, the order cannot matter — which is the synchronous point, made without a sentence. It is your figure's layout, and the same idea as the Layers page's sheets (one sheet a layer).
