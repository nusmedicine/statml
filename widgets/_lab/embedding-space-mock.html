1 · Page 1, Amino acids: twenty tokens in four roles, the table trained on a role task, its rows drawn as points

The task: class 1 carries hydrophobic · hydrophobic · positive · negative somewhere, each slot a random residue of that role; class 0 carries nothing. No single letter is the cue, so the table can only learn the roles. The twenty rows of Embedding(21, 8) are projected onto their top two principal components, each frame's own, laid over the final frame by a rotation (measured: the raw projection reflects and spins; this holds it still). Colour is the TRUE role, which nobody typed in; the position is what training put there. At epoch 0 the rows are N(0, 1), as nn.Embedding initialises them.

3 · The position pages (08-1 cell 1 §2, 08-3 cell 4 §2): learned · fixed sinusoidal · relative, a rotation

The lesson's claim: attention on its own treats a sequence as an unordered set, so x̃i = xi + pi adds a position vector to each token's embedding; a relative encoding (a rotation of q and k, RoPE) makes the attention score depend on the offset i − j alone. Measured on an ORDER task — two motifs both present, class 1 when the first precedes the second, the same bag of tokens in both classes — a head with no position sits at 48–49% while it learns a presence task at 77–84%; each of the three learns the order (83–93%); and when the SAME tokens are moved to positions 24..47, learned falls to chance, sinusoidal below it, and the rotation's scores do not change to the last digit. What does not hold: the learned table does not become ordered on this task (its nearest row is i ± 1 for 21% of positions, the sinusoid's 100%), and with real tokens prepended every encoding falls — that is one head and a mean pool diluted over twice the tokens, so the page moves the POSITIONS and claims nothing about longer sequences.
