tensors · a fifth dimension, drawn

Your question: when an operation makes a fifth dimension, extend the diagram instead of declining. Two different things make one, and they cost very differently. Nothing has been changed for this page.

§1 · A fifth dimension of size 1 — cheap, and I would build it

unsqueeze at rank 4 at positions 1–4, and reshape to five dimensions (which always contains a 1, since 40 = 2·2·2·5), make a [2, 2, 2, 5] with one size-1 dimension somewhere. That is exactly what the size-1 mark already draws at ranks 1–4: the rank-4 figure, with the solid highlight frame round each block the new dimension wraps. Position 0 is drawn today (the frame round everything); the other four are the same device one level further in. The stack view hugs each stack, each slab, each row, or sits inside each cell.

§2 · A real fifth dimension — dearer, and only stack at rank 4 needs it

torch.stack([T, T2]) at rank 4 makes [2, 2, 2, 2, 5]: eighty values and no size-1 dimension. That needs one more level of the drawing itself. Frames view: a frame per index of dim 0, down the page, each holding today's rank-4 figure — the picture is twice as tall as rank 4, and at 550px the cells are 18px. Stack view: today's rank-4 column once per index of dim 0, each in a dashed frame labelled dim 0 = f (the device round 21 uses for the size-1 case), so four exploded stacks down the page. The print is thirty-odd lines; it drops under the drawing. T2 is T + 40.

Worth it only if stacking four-dimensional tensors is something the lesson does; the notebook stacks at rank 3, where the result is drawn today. My recommendation: build §1, leave §2 declined with its message.
