Where do the numbers come from?

The notebook introduces five distributions as five named formulas with an r* call each. This page asks whether each one's generative story can be played out on screen instead — so a student picks a distribution by knowing the process, not by squinting at a histogram. Every example, parameter and R call below is the notebook's own, verbatim.

Each panel is one mechanism. The strip on top is one draw happening; the pile below is every draw so far. Watch the strip, not the pile — the pile is the part the notebook already draws.

Section 1 · How did these numbers get made?

Before any formula: somebody did something, and a number came out. Four processes, each played out on screen. The name at the top of each panel is the answer, not the question — the question is what the person was doing.

They come in two pairs, and inside each pair only one thing changes. Finding that one thing is the whole section.

Pair one — you decided up front how many times to look

Ten free throws. Fifty plots surveyed. A set number of tries, and you count the successes. The one thing that changes: whether each try has the same chance.

1 · Binomial — free throws, notebook cells 39–42

A fixed number of tries, each independent, each with the same chance. Count the successes.

2 · Hypergeometric — endangered species, notebook cells 51–54

The same counting, from a finite pool, without replacement. Watch the printed chance: in panel 1 it never moves, here it moves on every single draw.

Pair two — you watched one window and counted what turned up

One hour in A&E. One plot of ground. No set number of tries and no ceiling on the count. The one thing that changes: whether every window has the same underlying rate.

3 · Poisson — patients per hour, notebook cells 43–46

Events in a window, arriving at a rate that holds still. No ceiling on the count.

4 · Negative binomial — species per plot, notebook cells 47–50

The same window — but the rate itself is redrawn for every plot. That one change is the whole difference, and the rate marker is the only thing on this page that panel 3 does not have.
