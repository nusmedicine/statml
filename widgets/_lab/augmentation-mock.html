3 · The cases that fail

(a) The mask left out of keys. RandFlipd(keys=["image"], spatial_axis=0): the image flips, the mask stays. Measured: Dice 0.000 when the white cell is off-centre and 0.991 when it is centred, because a centred round mask maps onto itself. (b) Bilinear on the mask, after section 1's draw: a one-pixel ring of fractions that only a magnifier shows, and that AsDiscreted(threshold=0.5) returns to within a few dozen pixels of nearest.

4 · The Pipeline page: cell 19's listing

One epoch's sample through train_transforms: the first flip fires, the second does not, RandRotate90d draws k = 2, RandAffined fires with section 1's draw, RandAdjustContrastd draws γ 1.27, RandGaussianNoised does not fire. The fixed lines run once and are cached by CacheDataset; everything from the first random line down runs every epoch, AsDiscreted included (measured on MONAI).

5 · Which way is spatial_axis=0? — your call

Measured on MONAI 1.6.0: its readers load a 2D image x-first, so with cell 19 as written spatial_axis=0 mirrors the saved image left–right, and cell 27's permute(1, 2, 0) draws every sample transposed — in which the same flip looks top–bottom, as cell 15's comment says. Adding one argument, LoadImaged(keys=["image", "label"], reader="PILReader", reverse_indexing=False), was run the same night: the arrays load [C, H, W], cell 27's plots equal the files, and spatial_axis=0 flips top–bottom — the comment and the plots both right.
